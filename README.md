# MUD RING — кольцевая гонка с водными препятствиями

Браузерная аркада по мотивам MUD RACING: те же физика воды, тахометр с зелёной
зоной и оформление, но заезд — кольцо из двух кругов с лебёдкой на крутых выездах.

## Как устроена гонка

- **Кольцо.** Трасса MUD RACING замкнута: старт с верхней дорожки → финишная арка →
  нижняя дорожка → верхняя → нижняя → финиш. 4 отрезка = 2 круга, результат — общее время.
- **Лебёдка.** На каждой дорожке 1–2 случайных крутых выезда из воды. Без троса квадроцикл
  упирается в стенку. Тап по столбику (или клавиша `E`) — трос зацеплен; газом в зелёной
  зоне вытягиваешь наверх; ещё тап — трос отцеплен, можно ехать.
  Ниже зелёной зоны лебёдка не тянет и квадроцикл сползает, выше — мотор греется и глохнет,
  квадроцикл откатывается в лужу.
- **Уровни.** Новички / Любители / Профи отличаются шириной зелёной зоны (в воде и на
  лебёдке). **Экстрим** — как Профи, плюс: заглох в воде — заводи сам, иначе утонешь;
  два заглоха подряд на одной лебёдке — обрыв троса. В обоих случаях экран «Потрачено»,
  время не засчитывается.
- **Резина (Экстрим).** После «Старт» (и перед вопросом по регламенту) игрок выбирает резину
  на заезд; боты выбирают наугад. Параметры — `TYRES` в `src/core.js`:
  - **MudLite** — зелёная зона шире на 0.05 с каждой стороны (в воде и на лебёдке), скорость
    в воде −8 %.
  - **Assassinator** — скорость в воде +8 %, штраф подъёма ×0.6, лебёдка тянет на 15 % быстрее,
    зелёная зона уже на 0.04. Два заглоха подряд в воде (без выезда на песок между ними) —
    сход «Привод вышел из чата», экран «Потрачено».
  - Боты ошибаются в зависимости от резины (`err`: MudLite ×0.6, Assassinator ×1.3): реже или чаще
    перекручивают на лебёдке, а в каждой ванне с шансом `AI_WATER_ERR × (1.1 − skill) × err`
    перекручивают до заглоха (иногда дважды — на Assassinator это поломка привода).
- **Вопрос по регламенту (Экстрим).** Перед каждым стартом на Экстриме (в том числе «Ещё раз») —
  случайный вопрос из `questions.json`, варианты перемешаны. Верно — допуск к старту,
  неверно — на главную. Формат тот же, что в MUD RACING:
  `[{ "question": "…", "answers": ["…", "…"], "correct": 1 }]` (`correct` — номер с нуля).
  Файл — копия `../mudracing/questions.json`: новые вопросы добавлять в оба.
- **Масстарт.** Вместе с игроком стартуют 7 ботов (сетка за стартовой линией, место игрока
  случайное). Сила ботов — по уровню (`SKILL` в `src/game.js`), ИИ — `MR.makeAI` / `MR.aiStep`:
  ведёт газ в зелёной зоне, работает лебёдкой, иногда перекручивает; на Экстриме может
  оборвать трос или утонуть. Боты — полупрозрачные «призраки» без столкновений. На табло —
  живое место и отрыв в метрах; после финиша игрока боты доезжают «за кадром» и показывается
  протокол. В рекорды идёт время игрока и его место.
- Параметры — в `src/core.js`: `C.WINCH_*`, `C.ROLLBACK`, `C.BREAK_STALLS`, `ZW` (ширина
  зелёной зоны игрока по уровням; боты едут без поправки), профиль стенки — `WALL/TOP/PLAT/DOWN` в `makeTrack`.

## Структура

```
index.html        разметка + CSS
img/              фото экранов «Готов?», вопроса и «Потрачено» (встраиваются в сборку)
questions.json    вопросы по регламенту для Экстрима
src/core.js       трасса, физика, лебёдка (без DOM — работает в Node)
src/store.js      имя, рекорды (localStorage), запросы к серверу
src/sound.js      звук (WebAudio)
src/render.js     отрисовка: трасса, квадроцикл, столбики и трос, HUD
src/game.js       экраны, ввод, заезд
pwa/              манифест, service worker, иконки, инструкция по установке
build.py          сборка в docs/ (GitHub Pages)
tools/sim.js      прогон физики в Node
```

## Сборка

```bash
python3 build.py    # docs/index.html + PWA-файлы
```

## Рекорды

Локально — `localStorage` (`mudring.v1`). Общая таблица — тот же сервер, что у MUD RACING
(`mudracing/server`), адреса `/ring/scores`, таблица D1 `ring_scores`. Id игрока
(`mudracing.cid`) и имя общие с MUD RACING: обе игры живут на одном домене GitHub Pages.

## Проверка физики в Node

```bash
node tools/sim.js    # 5 трасс автопилотом + проверки: без лебёдки, перекрут, обрыв троса на Экстриме
```
